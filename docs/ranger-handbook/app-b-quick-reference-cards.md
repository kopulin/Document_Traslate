## B.2　九線醫療後送申請各線說明

**表 B-1．醫療後送申請九個線項的說明**

### 第 1 線——接運地點位置

| 項目 | 內容 |
|---|---|
| **說明** | 以**保密通信**傳送接運地點的方格座標。為避免混淆，訊息中須包含**方格區字母**。 |
| **何處、如何取得** | 由地圖或導航裝備判定接運地點的**軍用方格參考系統（MGRS）** 六位或八位方格座標。 |
| **通常由誰提供** | 單位領導者 |
| **原因** | 使後送載具知道到何處接運傷患。當後送載具須自**一個以上地點**接運、且協調後送任務的單位正在規劃路線時，尤須提供。 |

### 第 2 線——無線電頻率、呼號與後綴

| 項目 | 內容 |
|---|---|
| **說明** | **接運地點**該部無線電的頻率，**不是**中繼頻率。接運地點聯絡人的呼號與後綴可以**明語**傳送。 |
| **何處、如何取得** | 由自動網路管制裝置或其他核可方式取得。 |
| **通常由誰提供** | 無線電傳輸操作人員 |
| **原因** | 使後送載具在**途中**即可聯絡申請單位，取得補充資訊，或掌握狀況與指示的變更。 |

### 第 3 線——依優先順序區分的傷患人數

| 項目 | 內容 |
|---|---|
| **說明** | A——緊急（URGENT）<br>B——緊急手術（URGENT-SURG）<br>C——優先（PRIORITY）<br>D——例行（ROUTINE）<br>E——便利（CONVENIENCE）<br>同一次申請若回報**兩種以上**類別，各類別之間插入 **break**（分段）一詞。 |
| **何處、如何取得** | 由傷患評估結果取得。 |
| **通常由誰提供** | 醫務兵或現場資深人員 |
| **原因** | 掌管載具的單位據以**排定任務優先順序**。 |

### 第 4 線——所需特殊裝備

| 項目 | 內容 |
|---|---|
| **說明** | A——無<br>B——吊掛絞車（hoist）<br>C——脫困器材<br>D——呼吸器 |
| **何處、如何取得** | 由傷患評估或狀況判定。 |
| **通常由誰提供** | 醫務兵或現場資深人員 |
| **原因** | 使該裝備在任務出發**前**即已裝上後送載具。 |

### 第 5 線——依類型區分的傷患人數

| 項目 | 內容 |
|---|---|
| **說明** | **只回報適用的資訊**。若同時申請兩種類型的後送，在擔架與可行走兩項之間插入 **break** 一詞。<br>**L＋人數**——擔架（litter）<br>**A＋人數**——可行走（ambulatory，坐姿） |
| **何處、如何取得** | 由傷患評估結果取得。 |
| **通常由誰提供** | 醫務兵或現場資深人員 |
| **原因** | 使適當數量的後送載具前往接運地點，並以適當構型載運需後送的傷患。 |

### 第 6 線——〔戰時〕接運地點的警戒狀況

| 項目 | 內容 |
|---|---|
| **說明** | N——區域內**無**敵軍<br>P——區域內**可能有**敵軍，接近時注意<br>E——區域內**有**敵軍，接近時注意<br>X——區域內有敵軍，**需武裝護航** |
| **何處、如何取得** | 由狀況評估取得。 |
| **通常由誰提供** | 單位領導者 |
| **原因** | 協助後送機組評估狀況、判斷是否需要支援。後送載具常在**途中**才收到更明確的指導，例如敵軍的具體位置，以協助規劃航空器的進場。 |

### 第 6 線——〔平時〕傷、病的數量與類型

| 項目 | 內容 |
|---|---|
| **說明** | 傷患傷勢的**具體類型**資訊（例如槍傷或彈片傷）。如有嚴重出血一併回報，已知血型者亦回報。 |
| **何處、如何取得** | 由傷患評估結果取得。 |
| **通常由誰提供** | 醫務兵或現場資深人員 |
| **原因** | 協助後送人員判斷所需處置與特殊裝備。 |

### 第 7 線——接運地點的標示方式

| 項目 | 內容 |
|---|---|
| **說明** | A——布板<br>B——煙火信號<br>C——煙幕信號<br>D——無<br>E——其他 |
| **何處、如何取得** | 由狀況評估與器材可用性判定。 |
| **通常由誰提供** | 醫務兵或現場資深人員 |
| **原因** | 協助後送機組辨識確切的接運位置。**在後送載具抵達前聯絡該單位之前，不得傳送布板或煙幕的顏色**；基於安全考量，由**機組先說出顏色、單位再確認**。 |

### 第 8 線——傷患國籍與身分

| 項目 | 內容 |
|---|---|
| **說明** | A——美軍軍人<br>B——美國公民<br>C——非美軍軍人<br>D——非美國公民<br>E——敵俘<br>**不需**傳送各類別的人數。 |
| **何處、如何取得** | 由後送載具方取得。 |
| **通常由誰提供** | 醫務兵或現場資深人員 |
| **原因** | 協助規劃目的地設施與是否需要戒護。申請支援的單位須確保接運地點有**能說英語的代表**在場。 |

### 第 9 線——〔戰時〕化學、生物、輻射與核（CBRN）污染

| 項目 | 內容 |
|---|---|
| **說明** | C——化學<br>B——生物<br>R——輻射<br>N——核<br>**僅在適用時**才填列本線。 |
| **何處、如何取得** | 由狀況評估取得。 |
| **通常由誰提供** | 醫務兵或現場資深人員 |
| **原因** | 協助任務規劃，判定由哪一種後送載具執行任務、以及何時執行。 |

### 第 9 線——〔平時〕地形描述

| 項目 | 內容 |
|---|---|
| **說明** | 包含預定降落地點**周邊與場內**的地形特徵細節。以湖泊、山、塔等**顯著地形特徵**描述該地點的相對位置。 |
| **何處、如何取得** | 由地區勘查取得。 |
| **通常由誰提供** | 現場人員 |
| **原因** | 供後送人員評估進入該地區的路線或接近路線。在**吊掛絞車作業**時尤其重要。 |

> **圖例**：SURG 外科手術／U.S. 美國

> **譯註**：表 B-1 原文為「線項／項目／說明／何處如何取得／通常由誰提供／原因」六欄橫表，共九列（第 6、9 線各含戰時與平時兩種內容）。六欄橫表在中文排版與網頁上過寬難讀，譯文改為**每線一個小節、欄位直式排列**，內容與原文一一對應，未增刪。
